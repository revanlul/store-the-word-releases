# Store The Word for Mac — releases

Installers and update files for the Store The Word Mac app
([storetheword.com](https://storetheword.com)).

- **Install:** download the `.dmg` from the [latest release](../../releases/latest),
  open it, and drag Store The Word to Applications.
- **Updates:** the app checks this repository's latest release and offers new
  versions itself (Store The Word → Check for Updates…).

Releases are signed with the developer's Apple Developer ID and notarized by
Apple; update packages are additionally signed with the app's update key.
